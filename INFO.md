## 9. Papan Warta Jemaat 📋

### 9.1 Logika Tampilan
- **Akan Datang** (`eventDate >= hari ini`) → tampil di landing publik dengan **countdown** ke hari H
- **Sudah Berlalu** (`eventDate < hari ini`) → **disembunyikan** dari landing publik (tetap tersimpan di database untuk arsip admin)

### 9.2 Kategori Warta
| Kategori | Komunitas |
|---|---|
| `general` | Ibadah Raya / Umum |
| `youth` | Grow Generation Youth |
| `kidz` | COC Kidz (Sekolah Minggu) |
| `hana` | Wanita HANA & Komsel |

### 9.3 Field Warta
- `title` (judul)
- `content` (isi / deskripsi)
- `eventDate` (tanggal kegiatan — ISO date `YYYY-MM-DD`)
- `endDate` (tanggal selesai, opsional)
- `isPinned` (sematkan ke paling atas)
- `isPublished` (tayangkan atau draft)
- `badgeText` (label badge, mis. "Penting / Khusus")
- `author` (penulis / unit pelayanan)

### 10.2 5 Modul Utama
| Tab | Modul |
|---|---|
| 🔔 Warta Jemaat | CRUD warta + pin/unpin + filter publish/draft |
| 👥 Roster Pelayanan | Plotting pelayan 4 komunitas + WhatsApp broadcast + cetak A4 |
| 🫶 Layanan Jemaat | Permohonan doa, baptisan, komsel, volunteer |
| 🎬 CMS Khotbah & Galeri | Kelola khotbah + YouTube sync + foto Drive |
| 📦 Inventaris & Cek | Checklist sound system, multimedia, musik, ruangan |

### 10.3 Sumber Data
- **Supabase PostgreSQL** (primary, real-time)
- **localStorage** (offline cache, fallback)

### 10.4 Backend Endpoint
| Endpoint | Auth | Fungsi |
|---|---|---|
| `POST /api/auth/login` | public | Verifikasi PIN, set session cookie |
| `POST /api/auth/logout` | session | Clear session |
| `GET /api/auth/check` | session | Cek validitas session |
| `GET /api/admin/data?table=…` | session | Read table (admin only) |
| `POST /api/admin/data` | session | Upsert rows (admin only) |
| `DELETE /api/admin/data?table=…&id=…` | session | Hapus row (admin only) |
| `GET /api/public/data?table=…` | public | Read publik (filtered, sanitized) |
| `POST /api/public/ministry-requests` | public + rate limit | Submit permohonan |
| `POST /api/gallery/upload` | public (multipart) | Upload foto ke Drive + Supabase |
| `POST /api/gallery/sync` | session atau `x-sync-secret` | Sinkronisasi Drive → DB |
| `GET /api/youtube/latest` | public | Fetch 6 video khotbah terbaru |

## 11. Environment Variables 🔐

Lihat `.env.example` untuk dokumentasi lengkap. Singkat:

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
SUPABASE_ACCESS_TOKEN=

# Admin Auth
NEXT_PUBLIC_ADMIN_PASSWORD=1515
ADMIN_SESSION_SECRET=<random-32-char>

# Google Drive (OAuth)
GOOGLE_OAUTH_CLIENT_ID=
GOOGLE_OAUTH_CLIENT_SECRET=
GOOGLE_OAUTH_REFRESH_TOKEN=
GOOGLE_DRIVE_UPLOAD_FOLDER_ID=
GOOGLE_DRIVE_PUBLIC_FOLDER_ID=

# YouTube Data API v3
YOUTUBE_API_KEY=
YOUTUBE_CHANNEL_ID=

# Zoom (Ibadah Doa Pagi)

```

## 12. Catatan & Prinsip Pemeliharaan 🛠️

1. **Setiap perubahan informasi di file ini** → harus disinkronkan ke `seedData.ts`, `layout.tsx` (metadata), `LocationContactSection.tsx` (kontak), `ScheduleSection.tsx` (jadwal), `GivingSection.tsx` (metode persembahan).
2. **Jangan hardcode nomor rekening / data sensitif** di komponen publik — gunakan env var.
3. **Default password `1515`** hanya untuk setup awal; production harus override via `ADMIN_PASSWORD` env var.
4. **Link Zoom ibadah do'a pagi** masih sementara dan akan diperbarui — tandai TODO saat diperbarui.
